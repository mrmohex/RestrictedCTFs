# RestrictedCTFs

A Linux-based CTF challenges that tests your enumeration and privilege escalation skills.

Explore the environment, find hidden weaknesses, and try to gain access to the ultimate objective.

**Good luck, and happy hacking!**

---

## 📌 Description

- **Platform:** Linux
- **Category:** Privilege Escalation
- **Difficulty:** Easy & Medium
- **Environment:** Ubuntu 24.04
- **Required:** Docker

## 🚀 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/mrmohex/RestrictedCTFs.git
```
### 2. Run the challenge
```bash
cd RestrictedCTFs
cd RestrictedCTFs/RestrictedCTF_Medium
./start
```
### 3. Start hacking!

You're now inside the challenge environment.

Explore your surroundings, enumerate everything, and find a way to reach your objective.

Run it in an isolated Docker environment. Do not expose the challenge container to untrusted networks.
